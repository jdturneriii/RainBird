Initial generation: Rain Bird (ESP-Me / LNK WiFi) local-network plugin built on pyrainbird (MIT). Controller node (connection status + Discover), one Rain Bird unit node (watering state, rain delay, rain sensor, water budget; Stop All / Set Rain Delay / Set Water Budget / Run Program), and one zone node per available station (On/Off, run time) with customer-typed zone names via customTypedParams. pyrainbird is async, so a private asyncio loop thread serialises every call (the controller handles one client at a time) and polling pauses on password failure/lockout.
